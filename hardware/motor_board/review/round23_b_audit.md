## Notes (no action required)

- **N1 — no-encoder resume preset (:675).**  The preset is "V_q = ω·λ from the encoder speed".  In the no-usable-encoder branch there is no speed, so the preset is implicitly 0 after the fixed coast-down.  Saying "preset 0" there would close the gap.
- **N2 — §9 step 2 resume without motors or sensors (:733).**  With nothing connected the encoder inputs are frozen high, and at standstill firmware cannot tell "rotor still" from "no encoder" (:614 Lost encoder).  The resume would either align (B23-01) or wait the fixed coast-down time, which is only measured in §9 step 6.  A bench build needs a "no motors" mode that releases directly.  "So it only releases" implies this, but does not state it.
- **N3 — BKINE window wording (:675).**  "Only for steps 2–4, a few ms" is true only because the Z wait and the fixed coast-down wait come before the "Then disable…" sentence inside step 2.  "Only from the BKINE = 0 write to step 4, a few ms" would be unambiguous.
- **N4 — retry spacing (:675 vs :677).**  In the no-angle case an OCP is "retried every ~0.5 s", but step 4's nFAULT-still-low branch says "repeat from (2)" at once.  The two rules are compatible if the ~0.5 s spacing governs any resume-OCP retry; saying so would help.
- **N5 — punctuation (:731).**  "Measure U2's strap pins against AGND (MODE ~1.2 V …" never closes its parenthesis.  This is cosmetic.
